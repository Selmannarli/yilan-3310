# Yılan II — 3310 Edition

Nokia 3310 döneminin tek renkli LCD estetiğinden ilham alan, tarayıcıda çalışan klasik yılan oyunu.

## Özellikler

- Ok tuşları ve WASD ile kontrol
- Dokunmatik ekranlar için yön tuşları
- Oyun ilerledikçe artan hız
- Cihazda saklanan rekor
- Duraklatma ve yeniden başlatma
- Mobil ve masaüstü uyumlu tasarım

## Çalıştırma

```bash
npm install
npm run dev
```
